## Riva Fashion Store Database

### Overview

This project was developed as part of the Introduction to Database course at the University of Technology and Applied Sciences (UTAS).

The scenario focuses on Riva, a fashion brand specializing in women's clothing, footwear, accessories, and fragrances. The project involves designing a relational database to manage customers, their phone numbers, orders, and products.

### Objectives

Identify entities, attributes, primary keys, and relationships.

Design an Entity-Relationship Diagram (ERD).

Convert the ERD into a relational schema.

Apply database normalization from Unnormalized Form (UNF) through First, Second, and Third Normal Forms (1NF, 2NF, and 3NF).

Implement database tables and practice SQL commands.

### Database Entities

Customer: Stores customer information.

Cust_Phone: Stores customer phone numbers.

Order: Stores order details.

Product: Stores product information.

Contain: Represents the relationship between orders and products, including the order date.

### Business Rules

A customer can purchase multiple products, while each product is associated with one customer.

An order contains multiple products.

A product can appear in multiple orders.

The date is recorded when a product is included in an order.

A customer can have multiple phone numbers.

### Database Design

The project includes an ERD, a relational schema, and normalization tables illustrating how the database structure is organized to reduce redundancy and improve data integrity.

SQL Implementation

SQL commands were used to create and modify the database tables. The work also includes ALTER TABLE and UPDATE operations.
